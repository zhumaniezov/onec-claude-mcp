# Проверка комплекта

Проверка проведена 20 ноября 2026 года на Windows. Для неё созданы отдельные файловые базы с тестовыми справочником и документом и локальные публикации Apache. Регистрация в Claude Code выполнена в изолированном каталоге настроек.

| Что проверено | Результат |
| --- | --- |
| Регистрация готового dist/server.cjs в Claude Code 2.1.317, Node.js 24.22.2 | Команда claude mcp get вернула **Connected**. Проверена передача пользовательской переменной окружения дочернему серверу. |
| Протокол и обработка данных | Прошли 25 автоматических тестов. Ещё один запуск двух интеграционных тестов воспроизвёл stdio-сценарий на готовом файле дистрибутива. |
| Настоящая файловая публикация 1С 8.3.27.1644, Apache 2.4.71 | Из MCP-клиента через поставляемый сервер успешно созданы, прочитаны, изменены, помечены и физически удалены элемент справочника и документ. Контрольное чтение после удаления вернуло HTTP 404. Проверены выбор полей и фильтрация списка. |
| Оба компонента под одной учётной записью | На публикации с CFE 1.1.0 один профиль получил ограничения расширения, отказ на слишком длинную строку и затем выполнил полный цикл для корректного элемента справочника, включая обнаружение устаревшего плана и физическое удаление. |
| Предпросмотр и конфликт версий | Два плана созданы на одной версии объекта. После применения первого коннектор остановил второй при повторном чтении. Прямой запрос со старым If-Match платформа приняла, что оставляет окно гонки с внешним сеансом между чтением и записью. |
| Сверка результата | При записи без роли расширения 1С укоротила наименование с 27 до 25 символов. Коннектор вернул Description в verification.differences. |
| Права и длины полей в CFE 1.1.0 | Без роли сервис вернул 403. Работая от имени ограниченного читателя, MCP нашёл один доступный справочник. Сервис расширения вернул длины Description 25, Code 9 и пользовательского реквизита 60. Имя скрытого реквизита в ответе сервиса отсутствовало. Закрытый и отсутствующий объекты дали одинаковый 404. Строка из 26 символов отклонена на этапе подготовки изменения. |
| Загрузка самого CFE | Конфигуратор загрузил и применил расширение на 8.3.18.1208 и 8.3.27.1644. Проверка модулей завершилась без ошибок. Проверена применимость к конфигурации с английским основным языком. |
| Статические проверки расширения | Валидаторы CFE, роли, HTTP-сервиса и официальный CLI BSL Language Server 1.0.5 выполнены. Ошибок нет. Валидатор CFE отметил отсутствие собственного языка, BSL CLI — сложность обработчика и информационные замечания. MCP-навигация в текущей интеграции Codex недоступна. |

Реальная проверка CRUD относится к двум объектам стендовой конфигурации на 8.3.27.1644. Клиент-серверный кластер, облачный провайдер, проверки заполнения и обработчики конкретной прикладной конфигурации требуют отдельной приёмки при подключении соответствующей базы. Большие числа, составные ключи регистров при чтении и табличные части проверены автоматическими тестами на HTTP-стенде.
